# Introduction

> *"Kit and caboodle" — from Dutch* boedel*, one's whole estate and effects.
> Everything, together, nothing left on the dock.*

The quipu stack has a store that governs what a fact may claim (quipu), a keeper
that decides how knowledge earns its way in (camayoc), an index that serves it
back into agent context (bobbin), and a graph that knows what your code touches
(yupana). What it did not have is the first hour: a fresh machine, a person or
an agent, and a working stack at the end of it.

Caboodle is that first hour. It is an **AI-installable install wizard**: an LLM
agent — or a human answering the same interview — drives the install end to end,
and every claim along the way is a proof, not a banner.
