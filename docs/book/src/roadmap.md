  checksummed release installs; atomic state; clean-machine CI test.
- **Phase 1** — the LLM-guided interview and `skills/caboodle` are shipped.
  Camayoc bootstrap integration uses its checksum-pinned distribution until
  `core.qpack` is published, with a verified first ingest. The fresh-VM
  end-to-end demo remains.
- **Phase 2** — metrics contracts, generated Prometheus config, starter alerts,
  one dashboard; yupana + desire-path adapters; the quipu/beads emitters.
- **Phase 3** — the crew profile (shantytown / creel / both); `caboodle
  upgrade`; per-repo CI keeping conventional verbs tested with releases.
