# The stack README standard

Every public repo in the stack (caboodle, quipu, camayoc, bobbin, yupana,
desire-path) follows one README shape and one theme, so a reader who knows one
can find their way around the others: try it first, then this book for depth.

- [The standard](https://github.com/scbrown/caboodle/blob/main/docs/stack/README-STANDARD.md):
  section order, theme, the shared stack block, the rules, the mdBook
  skeleton, and the review checklist.
- [The README template](https://github.com/scbrown/caboodle/blob/main/docs/stack/README-TEMPLATE.md):
  a fill-in-the-blanks README that already meets it.

Status: draft, under review with the yupana pilot before the other repos adopt it.
